# 조작과 연결

- 아래 버튼 또는 좌우 밀기: 전체 / 미터 / 곡 정보 / 가사 집중 화면.
- 미터 영역 두 번 누르기 또는 상단 스타일 버튼: 아날로그 / 디지털.
- 미터 영역 위아래 밀기 또는 상단 테마 버튼: 아날로그 5종, 디지털 3종.
- 화면 길게 누르기 또는 설정의 ‘지금 곡 인식’: 수동 인식. 무음에는 요청하지 않음.
- 설정: 감도(0VU 기준), 가사 지연 0.1초 단위, 자동 인식 간격/켜기, 밝기, 미리보기,
  Wi-Fi 이름/비밀번호와 AudD 토큰. 선택값은 NVS에 저장됨.
- 기본 가사 지연은 +6.4초입니다. 가사 지연이 양수이면 가사 표시가 늦어짐. LRC 자체의 양수 offset은 가사를 앞당기는 규칙으로 처리.

## 비밀값 입력

`.secrets.json`은 Git 제외이며 파일 권한은 0600으로 생성됩니다. 채팅이나 로그에 값을 붙이지 마세요.
파일은 `wifi_ssid`, `wifi_password`, `audd_token` 문자열을 담습니다.
ESP-IDF 환경을 활성화한 뒤 `python tools/provision.py`를 실행하면 USB로 보드 NVS에 전달합니다.
보드 설정 화면에서도 값을 바꿀 수 있으며 비밀번호/토큰 입력란은 마스킹됩니다.
이 파일은 편의를 위한 로컬 파일이며 펌웨어 소스나 sdkconfig에 토큰을 넣지 않습니다.
보드 연결은 2.4GHz Wi-Fi를 사용합니다. C6 펌웨어는 이 작업에서 갱신하지 않습니다.

## 실제 표시와 미리보기

미리보기는 직접 작성한 시험 문구와 가짜 곡 정보입니다. 실제 인식 결과가 아니라는 문구를 표시합니다.
실제 곡을 인식하려면 미리보기를 끄고 음악을 재생하세요. 자동 인식은 기본 90초 간격이며,
3초 무음 이후 음악 시작과 곡 끝 예상 시점에도 요청합니다. HTTP 요청은 한 번에 하나씩 수행합니다.

AudD는 최근 8초 마이크 PCM을 16kHz 모노 WAV로 변환해 전송합니다.
LRCLIB는 곡명/아티스트/앨범/길이로 먼저 조회하고, 없으면 한 번 검색합니다.
시간 가사가 있으면 인식 위치와 경과 시간을 더해 표시하고, 일반 가사만 있으면 천천히 자동으로 넘깁니다.
한국어 가사 동기 오차는 실제 음악과 비교해 설정에서 조정해야 합니다. 마지막 20곡 가사는 PSRAM 캐시입니다.
앨범 아트는 HTTPS JPEG를 하드웨어 디코더로 풀어 PSRAM에 보관합니다. 표지가 없으면 회전 LP를 표시합니다. 표지 다운로드 실패 시5초 간격으로 총3회 재시도하며, 표지를 받으면 실제 앨범 아트로 전환합니다.

## 자료

- AudD: https://docs.audd.io/
- LRCLIB: https://lrclib.net/docs
- ESP32-P4 Wi-Fi 확장: https://docs.espressif.com/projects/esp-idf/en/v6.0.2/esp32p4/api-guides/wifi-expansion.html

가사 표시는 개인 사용 목적입니다. 배포·상품화 시 서비스 약관과 가사 표시 권한을 별도로 확인하세요.

## 집중 표시

메인 화면의 **다시 인식** 버튼으로 곡을 다시 인식할 수 있습니다. 처리 중에는 ‘다시 요청’, 추가 요청이 예약되면 ‘예약됨’으로 표시됩니다.
터치 없이 10초가 지나면 버튼·연결 상태·기타 보조 정보가 약 0.9초 동안 서서히 사라집니다.
**미터·가사·제목·앨범 아트는 그대로 남습니다.** 설정 화면은 자동으로 숨기지 않습니다.
한 번 터치하면 보조 정보가 약 0.2초 동안 다시 나타납니다. 이 첫 터치는 버튼 실행이나 화면 전환을 하지 않습니다.

USB로 공개 설정값만 바꾸려면 `python tools/set_option.py --lyric-delay-ms 6400`처럼 실행합니다.
양수는 가사를 늦춥니다. `--get`은 비밀값을 제외한 설정을 확인합니다.
범위 밖 입력은 보드에서 거부하며 이전 저장값을 유지합니다.

## 가사 종료와 인식 재시도

자동 인식이 켜져 있으면 가사 종료 시점에 다음 곡 인식을 바로 요청합니다.
LRC의 마지막 빈 시간 태그가 있으면 이를 종료로 사용합니다. 없으면 마지막 가사에 5초 여유를 주되 곡 길이를 넘기지 않습니다.
이전 곡이 다시 잡히면 재생 위치를 되돌리지 않고 8초 뒤 새 녹음으로 확인합니다. 무음에는 API 요청을 보내지 않습니다.

수동 인식은 누르는 즉시 접수합니다. 연결·소리가 준비되지 않았으면 최대 30초 대기하고,
매칭이 없거나 일시 오류이면 새 8초 구간으로 최대 3회 시도합니다. 토큰 오류는 반복하지 않습니다.
인식 중에도 ‘다시 요청’을 누를 수 있고, 추가 한 건을 예약합니다. 여러 번 눌러도 예약을 중복해서 쌓지 않습니다.

가사 집중 화면에도 표지를 별도로 표시합니다. 새 곡이 인식되면 이전 표지를 지우고 새 곡에 맞는 표지만 표시하며,
Apple 아트 다운로드/디코딩이 실패하면 Spotify의 표지도 시도합니다.
